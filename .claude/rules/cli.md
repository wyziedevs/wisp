# CLI (crates/wisp-cli)

- std only. Terminal output uses `term.rs` and the shared ui.css (violet accent): one look for the CLI, dev pages and built-in UI.
- `templates/vendor/**` is generated by `build.rs` from `examples/` and the repo's llms/AGENTS.md (minus its `<!-- repo -->` part): used by `wisp new`, `update-docs` and `mcp`. Never hand-edit it; `cargo build -p wisp-web` refreshes it, then commit the result.
- `wisp new` writes agent stubs that point at AGENTS.md at the app's root (new.rs). `mcp.rs` indexes llms/AGENTS.md and docs by heading, and a test builds `llms-full.txt` from them: renaming an AGENTS.md heading can break tests.
- `wisp dev` hot reload keeps `$state` (and header-literal state); markup edits never wait for cargo. Dev-only code stays out of release output.
- Deploy targets live in `src/targets/`; each must build with `wisp build --target X`.
- Test: `cargo test -q -p wisp-web`; for command changes also run the command in a scratch app (`wisp new`, `dev`, `build`).
